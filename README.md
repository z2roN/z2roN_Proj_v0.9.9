# z2roN_Proj v0.9.9 (엑셀처럼 행·열 데이터를 서버에 모아 여러 기기에서 쓰는 프로그램)

서버 = Windows 11 PC 1대(exe 1개, SQL 설치 불필요, 데이터는 파일 1개).
클라이언트 = 웹 브라우저(Windows·리눅스·아이폰·갤럭시 모두). 앱 설치 없음.

## v0.9.9: 서버도 자리수 달라도 조회·추가, 수량점검 상품명 표시
- 서버 창: 자리수가 다르면 경고음만 울리고 조회·추가는 그대로 진행 ("조회하지 않음" 옵션 제거)
- 폰 수량점검: 현재 시트를 상품 시트로 기본 선택해 상품명·매입가를 화면에 채움 (내보내기의 상품명 열은 선택, 기본 꺼짐)

## v0.9.8: 자리수가 달라도 조회 (폰·PC 웹)
- 바코드 조회·매입·가격POP·수량점검에서 지정 자리수와 다르면 경고음과 알림은 계속 나오지만 조회·추가는 막지 않고 그대로 진행(자료가 있으면 조회됨). 조회 결과 위에는 "⚠ 8자리 — 지정 자리수(13)와 다릅니다 — 자료는 조회되었습니다" 표시
- [자리수] 설정의 "자리수가 다르면 조회·추가 안 함" 옵션 삭제(이전에 켜 둔 기기도 자동으로 해제됨). 서버 창(Windows)의 자리수 옵션은 그대로

## v0.9.7: 서버 로그인 창 디자인 (스킨 적용)

## v0.9.4: 중복 바코드 지정 — 정렬 · 전체 한눈에 보기 · 체크박스 일괄 지정
- [중복 바코드 지정] 창의 모든 표에서 열 머리글을 누르면 정렬(예: 단위순), 머리글을 끌면 열 위치 변경
- 위쪽 [전체 한눈에 보기] 추가: 모든 중복 후보를 한 표에 펼쳐 놓고 정렬 → 체크박스로 선택 → [확인 — 체크한 행으로 지정]으로 한꺼번에 지정
- [이 단위로 체크]: 단위(예: 개)를 고르면 바코드마다 그 단위의 행을 한번에 체크(같은 단위가 여러 줄이라 정할 수 없는 바코드는 건너뛰고 알려줌). 체크를 확인·수정한 뒤 [확인]
- 한 바코드에 2개 이상 체크되면 그 바코드는 건너뜀. 기존 [바코드별 보기](왼쪽 바코드 → 오른쪽 후보)도 그대로 사용 가능

## v0.9.3: 수량점검 (폰에서 엑셀로 저장·공유)
- 폰 메뉴 [📋 수량점검]: 작업명을 정하고 바코드를 스캔하면 바로 추가되어 바코드·수량·매입가를 모음 (스캐너·카메라·직접 입력, 마지막 입력 삭제, 줄을 눌러 수량·매입가 수정/삭제, 키보드 켜기·끄기)
- 상품 시트를 고르면 상품명과 입고단가를 자동으로 채움(없으면 직접 입력, 시트에 없는 바코드도 수량은 기록)
- [📤 엑셀 내보내기]: xlsx 파일을 폰에서 직접 만들어 [내 파일로 저장] 또는 [공유](카카오톡·메일·드라이브 등). 상품명·합계 열은 선택. 서버로는 올라가지 않으며 작업 내용은 그 폰 브라우저에만 임시 저장됨
- 추가 프로그램 없이 xlsx 를 직접 생성(인터넷 없는 내부망에서도 동작)

## v0.9.1: 가격POP 스캔 즉시 추가 · 마지막 입력 삭제 · 삭제 스캔
- 가격POP 작업 화면: [추가] 버튼 없이 바코드를 스캔(스캐너·키보드 입력)하면 잠깐 멈춘 뒤 자동으로 추가됨 (Enter 도 그대로, 자리수 설정이 켜져 있으면 지정 자리수에 맞을 때 추가)
- [↩ 마지막 입력 삭제]: 방금 스캔한 것을 취소(새 상품이면 목록에서 제거, 이미 있던 상품이면 장수만 되돌림). 여러 번 누르면 순서대로 거슬러 올라감
- [🗑 삭제 스캔 모드]: 켜 두고 바코드를 스캔하면 그 상품이 목록에서 삭제됨(카메라 스캔도 동일). 모드가 켜져 있으면 빨간 안내가 표시됨

## v0.9.0: 가격POP 할인가 기준 가격 선택
- 새 작업 설정에 [할인가 계산 기준 가격] 추가: 소비자가·판매가1~10·입고가 등 시트의 가격 열 중 어느 가격에서 할인가를 만들지 직접 선택
- 기준 가격이 입고가(열 이름에 입고·원가·매입 포함 또는 입고단가 열과 같음)이면 [마진율 %] → 입고가 × (1 + 마진%), 그 밖의 가격이면 [할인율 %] → 가격 × (1 − 할인%). 화면의 이름과 설명이 자동으로 바뀜
- [정가 열]은 라벨에 줄을 그어 보여줄 가격(기준 가격과 따로 선택 가능). 이전 버전에서 저장한 작업은 그대로 열림

## 기능
- **서버 화면(관리자 창)**: 서버 PC 에서 바로 데이터 조회·검색·정렬, 셀 직접 수정(바로 저장), 행 추가·삭제, 엑셀 올리기·받기, 시트·열 설정, 사용자 관리, 접속·작업 기록, 백업. 창을 닫으면 트레이로 숨고 서버는 계속 실행됩니다.
- 시트(표) 여러 개: 열 이름 자유, 행 추가·수정·삭제·검색·정렬·페이지
- 엑셀(xlsx/xls)·CSV 올리기(새 시트/아래에 추가/덮어쓰기), 엑셀(xlsx) 받기
- 로그인(관리자/사용자/조회전용), 접속·작업 기록, 동시 수정 충돌 방지
- 백업: 관리자 화면에서 받기 + 서버 data\backup 에 매일 자동(14일 보관)
- 모바일: 브라우저로 접속 후 '홈 화면에 추가'

1. 빌드 결과 폴더(z2roN_Proj.exe 등)를 C:\z2roN_Proj 같은 곳에 둡니다.
2. 테스트: run.bat 실행 → 서버 관리 창이 열림. 브라우저(클라이언트)에서 http://localhost:8080 → 첫 화면에서 클라이언트용 관리자 계정 만들기
3. 상시 운영(권장): 서버 창 [서버 설정]의 [방화벽 포트 열기]·[Windows 시작 때 자동 실행 켜기] (또는 install_autostart.bat 을 관리자 권한으로 실행) (방화벽 허용 + Windows 로그인 때 자동 실행, 관리 창은 트레이). 서버 PC 는 자동 로그인(netplwiz) 설정 권장
   - 화면 없이 부팅 직후 실행만 원하면 install_service.bat (이 경우 서버 관리 창은 없음)
   - 실행 옵션: --tray(트레이로 시작), --nogui(창 없이)
4. 같은 공유기 안의 다른 기기: http://서버PC내부IP:8080  (서버 PC 내부 IP는 공유기에서 고정하세요)

## 외부 접속 (DDNS)
1. 공유기: 서버 PC 내부 IP 고정 → 포트 포워딩(외부 포트 → 서버 PC:8080) → DDNS 등록
2. 접속 주소 http://내DDNS주소:포트 (인증서 없이는 비밀번호가 암호화되지 않으므로 아래 HTTPS 권장)
3. HTTPS: 인증서(.pfx)를 만들어 config.json 의 pfx, pfxPassword 에 적고 서버 재시작
   - 인증서 발급 예: win-acme(Let's Encrypt, 무료) 로 DDNS 도메인 인증서를 .pfx 로 내보내기
   - 대안(포트를 열지 않음): Tailscale 또는 Cloudflare Tunnel (무료)
4. 통신사 CGNAT(공유기 WAN IP 가 사설 주소)이면 DDNS 로 접속되지 않습니다.

## config.json
`port`(기본 8080), `pfx`/`pfxPassword`(HTTPS), `dataDir`(데이터 폴더, 기본 서버 폴더의 data)

## 데이터
data\z2roN_Proj.db (SQLite 1개). 모든 시트·사용자·기록이 들어 있어 이 파일만 복사하면 이전·복구됩니다.
셀 값은 문자로 저장되고 정렬 시 숫자 모양은 숫자순으로 정렬됩니다. xlsx 로 받을 때 숫자 모양은 숫자 셀로 나갑니다(앞이 0인 코드·전화번호는 문자 유지).
